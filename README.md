# Road Accidents Analysis Dashboard – Tableau

## Overview

This project presents an interactive Tableau dashboard for analyzing Indian road accident data.

The dashboard contains 20,000 accident records and provides insights into accident frequency, fatalities, casualties, causes, road types, cities, day types, time of day, and risk scores.

## Tools Used

- Tableau Public

## Dataset

The dataset contains 20,000 road accident records with information related to:

- Accident date and time
- City and state
- Road type
- Weather
- Traffic density
- Accident cause
- Accident severity
- Casualties
- Vehicles involved
- Risk score
- Weekend / weekday
- Time of day
- Geographic coordinates

## Key Dashboard Metrics

- Total Accidents: 20,000
- Fatal Accidents: 2,987
- Fatality Rate: 14.94%
- Casualties: 34,529
- Average Risk Score: 0.44

## Dashboard Analysis

### Fatal Accidents by Day Type
Compares fatal accidents occurring on weekdays and weekends.

### Road Type-wise Fatalities
Shows the distribution of fatalities across:

- Urban
- Rural
- Highway

### Number of Accidents by Hour
Analyzes the number of accidents occurring throughout different hours of the day.

### Cause-wise Fatal Accidents
Compares major causes associated with fatal accidents, including:

- Poor Road
- Drunk Driving
- Overspeeding
- Weather
- Distraction

### Accidents by City and Cause
Provides a city-level comparison of accident causes across major Indian cities.

### Fatal Accidents by Time of Day
Analyzes fatal accidents across:

- Late Night (0–4)
- Morning (5–11)
- Afternoon (12–16)
- Evening (17–20)
- Night (21–23)

## Dashboard Filters

The dashboard includes filters for:

- Year
- City

These filters allow users to explore the accident data interactively.
